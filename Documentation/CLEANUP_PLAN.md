All 150+ `.csproj` files in root are auto-generated by Unity from `.asmdef` files. These are:

- **Purpose**: Visual Studio / VS Code intellisense and compilation

- **Version Control**: Should be in `.gitignore`
- **Action**: **DO NOT DELETE MANUALLY** - Unity manages these
